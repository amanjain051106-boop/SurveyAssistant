Local Ollama LLM Configuration

Use a locally installed language model to interpret questions that rule-based matching cannot resolve. Requires Ollama running locally.

Click above to verify your local Ollama service.

💡 Recommendations for 4 GB RAM systems:

  • Use lightweight models like llama3.2:1b or qwen2.5:0.5b / qwen2.5:1.5b.
  • Run command in PowerShell: ollama run llama3.2:1b
  • Local models run 100% on your machine with no external network requests.
